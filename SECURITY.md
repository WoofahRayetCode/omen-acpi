# Security policy

Please report vulnerabilities that could cause boot failure, loss of the stock
recovery path, unsafe ACPI acceptance, or unintended modification of
`limine.conf` privately through GitHub's **Security → Report a vulnerability**
flow for this repository. Do not open a public issue containing an unpublished
exploit, raw firmware tables, DSDT/SSDT files, serial numbers, private paths or
other machine-derived firmware content.

Include the toolkit version, affected command, sanitized status or diagnostic
output and the smallest synthetic reproduction possible. Keep the normal boot
entry and external recovery media intact while the report is investigated.
